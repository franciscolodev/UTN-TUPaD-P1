TP de Listas + TP de Funciones (Francisco López)

-TP Funciones:
Objetivo:
Comprender y aplicar el uso de funciones en la programación, desarrollando algoritmos que implementen modularidad, reutilización de código y
una organización estructurada para resolver problemas.

-TP Listas:
Objetivo:
Desarrollar la comprensión y la capacidad de manipular listas en Python
mediante la aplicación de conceptos fundamentales como la indexación, la
modificación de elementos, el uso de métodos integrados y el manejo de
listas anidadas.
